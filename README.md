# 📚 Помощник за учене

Приложение за по-лесно учене. Качваш документ или снимка от учебния си материал, а изкуственият интелект прави тест само от него. След решаването получаваш процент успеваемост и списък с теми, върху които да наблегнеш.

## Как работи
1. Качваш PDF, текстов файл или снимка (или снимаш с камерата).
2. AI прави тест въз основа само на материала.
3. Решаваш теста и виждаш верните отговори с обяснения.
4. Получаваш общ процент и процент по теми.

## Технологии
- Python
- Streamlit (интерфейс, работи и на телефон през браузъра)
- Google Gemini API (генериране на въпроси)

## Как се стартира локално
```
pip install -r requirements.txt
streamlit run app.py
```
Нужен е файл `.env` с ключ: `GEMINI_API_KEY=твоят_ключ`
